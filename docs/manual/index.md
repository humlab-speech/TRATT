# Tratt manual

Tratt turns a recording of people talking into editable text, entirely inside your
web browser. You load a sound or video file, optionally let a speech-recognition
model write a first draft, correct that draft against the audio, and export the
result as a document, subtitle file or annotation file.

Nothing you load is uploaded anywhere. Tratt reaches the network to fetch itself
and, when you ask for one, a language model; see
[How Tratt uses the internet](privacy.md) for the whole list.

## Two ways of working

Most of Tratt is about one recording at a time: you add a file, transcribe it,
export it. That is what the next two sections describe, and it is where to start.

There is only one working surface, and it holds as many recordings as you like.
Add a second file and it joins the first in a list down the left-hand side, with
a queue that works through them one at a time while you edit the one that is
done. Nothing to switch on and nowhere else to go; see
[Working with several recordings](workbench.md).

The header also has a button, **Switch between light and dark mode**, for the
colour theme. Your choice stays on your own device, like everything else Tratt
keeps; see [How Tratt uses the internet](privacy.md).

## About this manual

Tratt is a fork of [OCTRA](https://github.com/IPS-LMU/octra) (Institute of
Phonetics and Speech Processing, LMU Munich), developed for the Visible Speech
platform by [Humlab](https://www.umu.se/humlab/) and
[Språkbanken CLARIN](https://sprakbanken.se/) at Umeå University.

Tratt has moved far enough from that starting point that the upstream manual is
no longer a useful companion: the recording, the local speech recognition, the
speaker handling, the export and the whole working surface are Tratt's own. This
manual is the one to read, and it assumes no knowledge of OCTRA.

This manual documents Tratt 3.3.x.
