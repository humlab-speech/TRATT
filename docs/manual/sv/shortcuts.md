# Tangentbordsgenvägar

Tryck **Alt + 8** inne i TRATT för att se samma lista för den vy du befinner dig
i, genererad ur appen själv.

Genomgående: **Ctrl** på Windows och Linux, **Cmd** på macOS, utom där de två
skiljer sig och båda anges.

---

## Var som helst under transkribering

| Tangenter | Åtgärd |
| --- | --- |
| **Alt + 8** | Öppna genvägsfönstret |
| **Alt + 9** | Öppna riktlinjefönstret |
| **Alt + 0** | Öppna Översikt |

---

## Ljuduppspelning

Dessa fungerar i alla vyer. I Linjär vy har den nedre visningen (luppen) en egen
uppsättning, se nedan.

| Tangenter | Åtgärd |
| --- | --- |
| **Tabb** | Spela / pausa |
| **Esc** | Stoppa |
| **Skift + Backsteg** | Hoppa tillbaka till senaste startläge för uppspelning |
| **Skift + Tabb** | Stega tillbaka i tid (hör det sista ögonblicket igen) |

---

## På vågformen

Finns i 2D Vy och Linjär vy, med musen över signalen och utan att något textfält
har fokus.

| Tangenter | Åtgärd |
| --- | --- |
| **S** | Sätt en enhetsgräns vid markören |
| **A** | Markera enheten under markören som tystnad (paus) |
| **D** | Ta bort de markerade gränserna och slå ihop enheterna |
| **C** | Spela den aktuella markeringen |
| **Enter** | Öppna transkriptionsfönstret för enheten under markören |
| **←** / **→** | Flytta markören åt vänster / höger |
| **H** | Spela ljud vid hovring |
| **Ctrl + Z** / **Cmd + Z** | Ångra |
| **Ctrl + Y** / **Skift + Cmd + Z** | Gör om |

---

## Transkriptionsfönstret (rutan i 2D Vy)

| Tangenter | Åtgärd |
| --- | --- |
| **Alt + →** | Spara och öppna nästa transkriptionsenhet |
| **Alt + ←** | Spara och öppna föregående transkriptionsenhet |
| **Alt + ↓** | Spara och stäng fönstret |
| **Ctrl + S** / **Cmd + S** | Växla enhetens talaretikett |
| **Tabb**, **Esc**, **Skift + Backsteg**, **Skift + Tabb** | Uppspelning, som ovan |

---

## Textfältet

Var du än skriver en transkription: transkriptionsfönstret, Diktafon-vyn eller en
rad i Översikt. Markörknapparnas texter visas på engelska även i det svenska
gränssnittet.

| Tangenter | Åtgärd |
| --- | --- |
| **Alt + 1** | `[~abc]`: ord avhugget i början |
| **Alt + 2** | `<nib>`: tvekljud |
| **Alt + 3** | `[int]`: tillfälligt ljud |
| **Alt + 4** | `[spk]`: ljud från talaren |
| **Alt + 5** | `[sta]`: konstant bakgrundsljud |
| **Alt + 6** | `**`: oförståeligt eller främmande ord följer |
| **Alt + 7** | `[abc~]`: ord avhugget i slutet |
| **Alt + P** | `<P>`: markera enheten som paus |
| **Alt + S** | Infoga ett beskärningsmärke: dela enheten vid uppspelningsläget och texten vid markören |
| **Ctrl + Z** / **Cmd + Z** | Ångra |
| **Ctrl + Y** / **Skift + Cmd + Z** | Gör om |

Markörerna kommer från projektets riktlinjefil. En annorlunda konfigurerad
installation kan erbjuda en annan uppsättning. Verktygsraden ovanför textfältet
visar alltid sanningen.

## Linjär vy: de två visningarna

| | Övre (överblick) | Nedre (lupp) |
| --- | --- | --- |
| Spela / pausa | **Tabb** | **Skift + Blanksteg** |
| Stoppa | **Esc** | **Esc** |
| Tillbaka till senaste läge | **Skift + Backsteg** | **Skift + Enter** |
| Stega tillbaka i tid | **Skift + Tabb** | **Skift + \*** |

---

## TRN-Editor-tabellen (experimentell)

Listad för fullständighetens skull. TRN-Editor erbjuds inte i vyväljaren och är
inte färdig; dess genvägar är inte inkopplade. Se
[Vyerna](the-editors.md#trn-editor--experimental).

| Tangenter | Åtgärd |
| --- | --- |
| **Enter** | Spara cellen och gå till nästa |
| **Alt + ↑ / ↓ / ← / →** | Spara cellen och flytta i den riktningen |
| **Ctrl/Cmd + A** | Markera alla segment |
| **Ctrl/Cmd + Backsteg** | Ta bort de markerade segmenten helt |

---

## De tre du faktiskt behöver

Allt ovan är referens. I det dagliga arbetet är det:

**Enter** för att öppna en enhet · **Tabb** för att höra den · **Alt + →** för att
spara och gå vidare.
