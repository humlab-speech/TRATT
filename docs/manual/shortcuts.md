# Keyboard shortcuts

Press **Alt + 8** inside TRATT to see the same list for the editor you are currently
in, generated from the app itself.

Throughout: **Ctrl** on Windows and Linux, **Cmd** on macOS, except where the two
differ and both are given.

---

## Anywhere while transcribing

| Keys | Action |
| --- | --- |
| **Alt + 8** | Open the Shortcuts window |
| **Alt + 9** | Open the Guidelines window |
| **Alt + 0** | Open the Overview window |

---

## Audio playback

These work in every editor. In the Linear Editor the lower (loupe) display has its
own set; see below.

| Keys | Action |
| --- | --- |
| **Tab** | Play / pause |
| **Esc** | Stop |
| **Shift + Backspace** | Jump back to the last playback start position |
| **Shift + Tab** | Step back in time (re-hear the last moment) |

---

## On the waveform

Available in the 2D-Editor and the Linear Editor, with the mouse over the signal and
no text field focused.

| Keys | Action |
| --- | --- |
| **S** | Set a transcription-unit boundary at the cursor |
| **A** | Mark the unit under the cursor as silence (break) |
| **D** | Delete the selected boundaries and join the units |
| **C** | Play the current selection |
| **Enter** | Open the transcription window for the unit under the cursor |
| **←** / **→** | Move the cursor left / right |
| **H** | Play audio while hovering |
| **Ctrl + Z** / **Cmd + Z** | Undo |
| **Ctrl + Y** / **Shift + Cmd + Z** | Redo |

---

## Transcription window (the pop-up in the 2D-Editor)

| Keys | Action |
| --- | --- |
| **Alt + →** | Save and open the next transcription unit |
| **Alt + ←** | Save and open the previous transcription unit |
| **Alt + ↓** | Save and close the window |
| **Ctrl + S** / **Cmd + S** | Cycle this unit's speaker label |
| **Tab**, **Esc**, **Shift + Backspace**, **Shift + Tab** | Playback, as above |

---

## Text field

Wherever you are typing a transcription: the transcription window, the Dictaphone
Editor, or an Overview row.

| Keys | Action |
| --- | --- |
| **Alt + 1** | `[~abc]`: word cut off at the start |
| **Alt + 2** | `<nib>`: filled pause |
| **Alt + 3** | `[int]`: intermittent noise |
| **Alt + 4** | `[spk]`: speaker noise |
| **Alt + 5** | `[sta]`: stationary noise |
| **Alt + 6** | `**`: unintelligible / foreign word follows |
| **Alt + 7** | `[abc~]`: word cut off at the end |
| **Alt + P** | `<P>`: mark this unit as a break |
| **Alt + S** | Insert a crop mark: split the unit at the playback position and the text at the cursor |
| **Ctrl + Z** / **Cmd + Z** | Undo |
| **Ctrl + Y** / **Shift + Cmd + Z** | Redo |

Markers come from the project's guidelines file. A differently configured
installation may offer a different set; the toolbar above the text field always
shows the truth.

## TRN-Editor table (experimental)

Listed for completeness only. The TRN-Editor is not offered in the editor switcher
and is unfinished; its shortcuts are not connected. See
[The editors](the-editors.md#trn-editor--experimental).

| Keys | Action |
| --- | --- |
| **Enter** | Save the cell and go to the next |
| **Alt + ↑ / ↓ / ← / →** | Save the cell and move in that direction |
| **Ctrl/Cmd + A** | Select all segments |
| **Ctrl/Cmd + Backspace** | Remove the selected segments completely |

## The three you actually need

Everything above is reference. Day to day it is:

**Enter** to open a unit · **Tab** to hear it · **Alt + →** to save and move on.
