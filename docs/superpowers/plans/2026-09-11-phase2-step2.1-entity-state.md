# Phase 2 Step 2.1 (Entity state, local mode only) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `localMode`'s registered NgRx feature state an `@ngrx/entity` collection of `AnnotationState`, holding exactly one hardcoded entity, with zero observable behaviour change — every existing selector, effect, and raw-state reader for LOCAL mode keeps working identically. This is the foundation 2.2 (per-bundle undo) and 2.4 (the sweep) build on.

**Architecture:** `onlineMode`/`demoMode`/`urlMode` are completely untouched — same flat `AnnotationState` feature slices as today. Only `localMode`'s registered shape changes, from `AnnotationState` to `LocalBundleCollectionState = { bundles: EntityState<AnnotationState>; selectedBundleId: string }`. The existing shared reducer code (`AnnotationStateReducers`, `LoginModeReducers`) is **not modified** — it keeps producing plain `AnnotationState` values. A new higher-order reducer wraps it for LOCAL only, routing every action to the single hardcoded entity and re-storing the result. A single `resolveLocalBundleState()` helper reconstructs the flat `AnnotationState` view from the entity collection, used at every one of the 3 chokepoints (plus 3 scattered call sites) that read LOCAL mode's state directly, bypassing NgRx selectors — found by exhaustive `grep` across the codebase, not assumption.

**Tech Stack:** `@ngrx/entity` (`~19.0.0`, already a dependency, first usage in this codebase — no existing local pattern to follow, use upstream `createEntityAdapter` docs).

**Spec:** `docs/superpowers/specs/2026-09-10-workbench-conversion-design.md` (see "Correction (found 2026-09-11...)" section — the plan's original premise of one `LoginModeState` does not match the codebase; there are 4 parallel `AnnotationState` slices, and only `localMode` needs entity treatment given the workbench's local-only scope).

## Global Constraints

- Zero behaviour change for `onlineMode`/`demoMode`/`urlMode` — literally untouched files/types.
- Zero *observable* behaviour change for `localMode` either — every existing consumer (selector-based or raw-state-based) must see the same `AnnotationState`-shaped data it sees today.
- Exactly one hardcoded bundle entity this step (`DEFAULT_BUNDLE_ID = 'bundle-1'`) — no UI for multiple bundles, no bundle list. That's 2.7+.
- `@ngrx/entity`'s `selectId` is intentionally a constant closure returning `DEFAULT_BUNDLE_ID` for now — this is correct for a one-entity step and gets replaced when 2.2/2.7 introduce real bundle ids, not a bug to fix here.

// apps/tratt/src/app/core/store/login-mode/annotation/local-bundle-collection.ts
import { createEntityAdapter, EntityAdapter, EntityState } from '@ngrx/entity';
import { AnnotationState } from './index';

export const DEFAULT_BUNDLE_ID = 'bundle-1';

export const localBundleAdapter: EntityAdapter<AnnotationState> =
  createEntityAdapter<AnnotationState>({
    selectId: () => DEFAULT_BUNDLE_ID,
  });

export interface LocalBundleCollectionState {
  bundles: EntityState<AnnotationState>;
  selectedBundleId: string;
}

export function resolveLocalBundleState(
  state: LocalBundleCollectionState | undefined,
): AnnotationState | undefined {
  return state?.bundles.entities[state.selectedBundleId];
}

- [ ] **Step 4: Implement the wrapper and wire it in**

Add to `login-mode.reducer.ts`:

```ts
function wrapAsLocalBundleCollectionReducer(
  innerReducer: ActionReducer<AnnotationState>,
): ActionReducer<LocalBundleCollectionState> {
  const initialInner = innerReducer(undefined, { type: '@ngrx/store/init' } as Action);
  const initialState: LocalBundleCollectionState = {
    bundles: localBundleAdapter.setOne(initialInner, localBundleAdapter.getInitialState()),
    selectedBundleId: DEFAULT_BUNDLE_ID,
  };

  return (state: LocalBundleCollectionState = initialState, action: Action): LocalBundleCollectionState => {
    const currentInner = resolveLocalBundleState(state) ?? initialInner;
    const nextInner = innerReducer(currentInner, action);
    if (nextInner === currentInner) {
      return state;
    }
    return {
      ...state,
      bundles: localBundleAdapter.setOne(nextInner, state.bundles),
    };
  };
}
```

export function getModeState(appState: RootState): AnnotationState | undefined {
