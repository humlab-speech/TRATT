# Phase 2 Step 2.5 (Audio residency) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give `AudioService` an eviction policy (full PCM for the selected bundle + 2 most recent; anything older gets its `AudioManager` destroyed to free memory) and a decode-time min/max envelope that survives eviction, so a re-selected-but-evicted bundle can paint instantly from the envelope while its PCM re-decodes. This is the memory-safety keystone for multi-bundle support (step 2.7).

**Architecture:** No new UI, no `BundleService` (not yet built — later step), no bundle-creation/selection UX (step 2.7's job). This step adds pure infrastructure to `AudioService`, proven with directly-constructed multi-manager test scenarios (the same technique step 2.2 used to prove per-bundle undo isolation before real multi-bundle ingest existed). LRU tracking hooks off the *existing* `selectedBundleId` signal (`store.selectSignal(selectSelectedBundleId)`, already in `AudioService` since step 2.3) via an Angular `effect()` — no new store/UI plumbing needed. The envelope reuses the existing `AudioViewerTimeUtils.computeDisplayData` min/max algorithm directly (it's a plain, synchronously-callable function with no worker-specific internals — verified) rather than duplicating the math.

**Tech Stack:** Angular `effect()` (precedent: `annotation.store.service.ts`'s constructor). No new dependencies.

**Spec:** `docs/superpowers/specs/2026-09-10-workbench-conversion-design.md` (see the "Finding (2026-09-11, during 2.5 planning)" section — the residency policy here is designed around the *actual* current architecture, not the original plan's two-simultaneous-PCM-copies assumption, which doesn't hold today).

## Global Constraints

- No behaviour change for the current single-bundle case — with only one bundle ever selected, eviction never triggers (cap is 3), so existing flows are unaffected.
- Envelope is in-memory only this step (not persisted to IndexedDB — confirmed no blob/binary object store exists yet; surviving reload is step 2.6's concern, not this one).
- Eviction frees `AudioManager` (PCM, blob URL) but the envelope for that bundle stays cached — that's the entire point.
- `onlineMode`/`demoMode`/`urlMode` untouched, as always (this is `AudioService`-wide but only `localMode` ever has more than one addressable id today).

```ts
// apps/tratt/src/app/core/shared/service/audio-envelope.ts
import { AudioViewerTimeUtils } from '@tratt/ngx-components';

export interface AudioEnvelope {
  columns: number;
  minMax: Float32Array;
}

const timeUtils = new AudioViewerTimeUtils();

export async function computeAudioEnvelope(
  channel: Float32Array,
  columns = 4000,
): Promise<AudioEnvelope> {
  const xZoom = channel.length / columns;
  const minMax = await timeUtils.computeDisplayData(
    columns,
    2, // height=2 -> yZoom=1, i.e. raw amplitude values, not pixel-scaled
    channel,
    { start: 0, end: channel.length },
    false,
    xZoom,
  );
  return { columns, minMax: Float32Array.from(minMax) };
}
```

- [ ] **Step 4: Implement eviction + LRU tracking + envelope caching in `audio.service.ts`**

```ts
import { computeAudioEnvelope, AudioEnvelope } from './audio-envelope';
import { effect } from '@angular/core';

// inside the class
export const MAX_RESIDENT_BUNDLES = 3; // or a static readonly field, match file style

private _envelopes = new Map<string, AudioEnvelope>();
private recentBundleIds: string[] = [];

constructor(
  private http: HttpClient,
  private store: Store,
) {
  effect(() => {
    const id = this.selectedBundleId();
    if (id) {
      this.trackSelection(id);
    }
  });
}

private trackSelection(bundleId: string): void {
  const idx = this.recentBundleIds.indexOf(bundleId);
  if (idx !== -1) {
    this.recentBundleIds.splice(idx, 1);
  }
  this.recentBundleIds.push(bundleId);
  while (this.recentBundleIds.length > MAX_RESIDENT_BUNDLES) {
    const oldest = this.recentBundleIds.shift();
    if (oldest !== undefined) {
      this.evict(oldest);
    }
  }
}

public evict(bundleId: string): void {
  const manager = this._audiomanagers.get(bundleId);
  if (manager) {
    manager.destroy();
    this._audiomanagers.delete(bundleId);
  }
}

public getEnvelope(bundleId: string): AudioEnvelope | undefined {
  return this._envelopes.get(bundleId);
}
```

```ts
public registerAudioManager(bundleId: string, manager: AudioManager) {
  if (manager !== undefined) {
    const existing = this._audiomanagers.get(bundleId);
    if (existing !== manager) {
      this._audiomanagers.set(bundleId, manager);
      this.subscrmanager.add(
```
